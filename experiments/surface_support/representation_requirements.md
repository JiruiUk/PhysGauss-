# 下一步表示与身份依据：尚未实施新候选

目前准入门槛未过：没有完整物体／表面身份，早期参考点也没有覆盖后续可见重建。以下为从本轮证据导出的实现要求，不是已验证方案或新增训练授权预算。

## 身份来源先于约束

- 合成器导出的 object ID + mesh/vertex/material ID 是最直接的依据；需要核对坐标、时间、相机及可见性。原始0/255 mask不满足要求。
- 如果只有图像，人工核验的实例掩膜可约束可见归属，但仅靠它不能确定遮挡后相同表面点。应保存多假设／未知状态，结合多视角、深度或可核验几何对应。若仍有歧义，保留未知，不以最近位置强行闭合轨迹。
- 图像局部标签、聚类、网络共享 latent、相同 kernel 下标均不能独自证明物体或材料身份。

## 一个可审核的结构方向

对已经确认身份的物体 `o`，保留 canonical 支持 `X_i, Sigma_i0` 和固定归属 `o_i`；用该物体的运动与形变 `x_i(t)=T_o(t) phi_o(X_i,t)` 生成中心。局部形变导数同时用于足迹的变换，例如 `Sigma_i(t)=J_i(t) Sigma_i0 J_i(t)^T`。这将中心与协方差置于同一个几何映射之下，不再允许两个独立解释各自绕开形态监督。

该表达式是几何耦合建议，**不是本构定律**。表面点的3D邻域可能秩亏，应在可识别的切向表示或受测估计器上验证，不能把全空间近邻直接当材料邻域。Gaussian渲染足迹也不等同真实材料体积，任何必要的剩余足迹自由度须单独有界并审计。

背景与未知点保留独立池。只有获得新的可验证证据，才允许变更归属；必须记录证据、时间、冲突与撤销机制。稠密化生成点只能继承已确认父点的身份，或保持未知，不能沿最近物体传播身份。

## 在形态与接触之前必须通过的验证

- 合成已知身份／遮挡测试能恢复对应；两物体接近、相交投影和分离时不换ID、不拉平。
- 真实训练序列全时段：物体可见区域由该物体已知支持解释，同时输出完整alpha贡献、中心和协方差，不只统计中心距离或截断元数据。
- 遮挡时不误判为身份消失；重新出现时有独立证据才恢复对应。孤立渲染、固定相机和固定足迹仅作诊断。
- flags-off走原C1/PIDG路径；新表示必须独立开关、单测、GPU短训、完整恢复，再考虑一个有界完整候选。不能先重训后再用PSNR证明物体身份正确。
- 通过后才分别加入：物体内参考拓扑上的形态约束；不同已知身份表面之间的接触几何约束。尚无依据的位置不加跨物体形态边，也不引入自由外力或未知材料拟合。
