## 判断与新证据

**当前可以将部分点归到一条连续可见的局部物体轨迹；不必先证明所有点始终对应同一块材料表面。** 应将“物体→多个表面点库→各时刻可见支持”作为关联结构。点库可以只解释物体的一部分，暂时不可见也不应立即改属另一只物体。

## 如何给一个点建立归属

1. **先跟踪图像物体。** 从分离轮廓创建局部身份，使用原始双向流，要求正反传播一一对应。分量编号会随帧变化，不能直接当身份；合并、分裂、丢失或反向不符的连接保持未知。
2. **再将Gaussian与当前轮廓连接。** 使用训练实际宽度1600的完整 `alpha*T` 贡献；至少0.02归一化贡献且95%以上在该轮廓内，投影中心位于腐蚀后的轮廓内、深度和协方差有效，源与目标均有这些支持，中心运动还需符合双向有效原始流，误差不超过2px@400。
3. **累积物体归属证据。** 同一固定行连续三个观测获得同一局部身份后才登记；时刻t的输出只读到t。无支持时保留历史关联，但当前可见归属为未知。曾明确支持两个不同局部物体的行永久标记冲突，不根据后续平滑运动消除它。
4. **在物体下容纳多个点库。** 对新点库先验证其图像轨迹与旧物体连接，再登记该库；允许新旧库部分重叠或不重叠。行号交集只能检查一致性，不能自行证明身份。

建议记录结构为 `checkpoint SHA → identity domain → local object → patch banks → canonical row IDs → per-observation support/conflict`。这不是已知材料ID `m_i`，也不是学习式材料分割。当前仅有局部观察证据，不给不可见行、边界行或其他未通过行填最近物体标签。

## 缓存诊断结果

86,143个冻结Gaussian行。早段2–27有2407行至少一次通过观测支持；至27有2065行积累足够历史归属证据，其中1556行在27当前仍通过支持。四组历史计数为236/224/299/1306；当前贡献覆盖率64.87%。晚段188–200独立初始化，1561行曾有支持；至200有1048行历史关联、694行当前可见，当前覆盖率52.70%。

两域内均未触发跨物体冲突。**零观测冲突不是全模型正确，也不是跨遮挡身份准确率。** 掩膜与流可能共同出错，弱纹理、中心/足迹门槛、单视角深度和选片偏差仍存在；也不能根据行数将剩余行判成错误。历史归属比当前可见行更多，正是两层状态不同的表现。

## 下一步的顺序

优先把这个物体点库注册延伸至首次自然合并前后，而不是直接开始本构/形态/接触训练：

- 先在实际训练分辨率扩展原28–42的连续支持；逐个物体报告旧库支持、新库补充、中心离开轮廓、足迹外溢与流不符。不能只用总覆盖率归因。
- 对43起首次合并分别记录图像身份是否失去一一对应、原物体点群是否仍有可见证据、分离后有哪些身份置换候选。二维身份不确定时停止自动并库，保留候选或新局部域。
- 新可见patch属于同一物体，只能建立物体级集合；计算F或构造本构邻域还要检验同物体内的材料邻接及持续对应，不能把整个物体所有点视作相邻材料。
- 只有当固定身份物体轨迹仍可信、而原Gaussian确实跨物体支持或无法维持预期持续表示时，再提出带独立开关的物体坐标表示改动；单凭不可见不能定为表示失败。观察完全对称的遮挡重现需要额外可辨别表面线索、视角或已知ID，运动平滑不能给出唯一答案。

上述延伸与模型改动尚未执行。原188–200与原2–27没有建立跨遮挡身份桥；晚期相同F编号/颜色不是早期同一只鸭子的结论。没有恢复旧P1/O0训练或自动跟进。
