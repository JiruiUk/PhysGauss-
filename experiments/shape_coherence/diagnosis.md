# C1 多物体形态诊断与局部形态候选

用户授权先诊断，再实现带开关的形态保持模块，测试与短训通过后做一个完整候选；历史 C1 不重训。本轮不引入外力、本构、材料参数或学习式分割。

## 已核验的现象

只读历史 C1 final50k，使用训练图像和完整中心轨迹 `R(t)X + T(t)`。早期五个训练帧 2/6/10/14/19 中，黄色图像连通区域可清楚分为四只鸭子；已人工查看五帧叠加图。按修正后的真实 alpha*T 混合贡献投票，获得四组早期表面参考点 189/177/197/698 个，未知点 84882 个，819 个通过距离与三维秩检查的邻域。不是完整物体 ID，也不是真实三维表面或材料分割。

帧2鸭子像素 MAE 为 .01016，帧50为 .02653，帧102为 .02356。早期局部邻域相对参考形态的非仿射残差随时间显著增大，但更重要的是这些早期点的可见贡献消失：早期约69%的鸭子像素贡献由这些点承担，中后段多帧降至零。已查看帧86的 GT、C1 与参考点颜色图。模型可能使用不同时间/视角活跃的高斯点完成重建；不能把所有点都当持续可见的同一材料点。形态问题不能据此简单归因为碰撞力缺失，也不能仅靠降低内部邻域残差宣称解决。

原 C1 opacity 本身不随时间变化，但完整形变和附加尺度改变点的位置与有效足迹。渲染尺度的负号在协方差 LLᵀ 中抵消，不等同于材料反转。与接近零的 canonical 尺度作比会夸大数值，因此诊断改用清晰参考姿态的有效绝对尺度。覆盖图未知点用实际颜色的灰暗版本显示，避免把背景高斯的统一亮灰覆盖误当真实几何。

## 候选与门槛

P1 从原完整3k共同起点训练；保留 C1 图像损失、时钟、独立速度/应力和原动量，不开光流。原稠密化15k结束后，在16k构建候选自身的固定参考邻域，暂停并人工检查。只在高置信同组点内连边，未知点不连。形态项分为局部非仿射残差与宽松的塌缩/过度拉伸约束，旋转不受罚；没有新参数或优化器组。

必须检查候选自身的早期标签和中段实际贡献后决定是否继续。若早期参考点不能可靠覆盖中段可见鸭子，不能把这项弱监督说成完整的物体形态约束。将记录失败门槛，不盲目训练或把分组当物理真值。有效覆盖仍然不能证明材料身份正确。

新损失仅对形变中心反传；独立 probe 已在真实 C1 优化器状态上确认 grid/deform 有有限梯度及实际参数更新，velocity/stress 与 canonical xyz 不接收直接形态梯度。图像/物理间接联动仍然存在。预先成功标准和预算见 plan.json；没有真实三维接触/应力 GT，且历史测试已有暴露。

probe 保留了真实 Adam 状态，其参数更新幅度还包含已有动量，不能把更新 L1 范数当成形态项独立贡献或有效性的度量。100步短训遵循原 PIDG 最后一步不执行 optimizer.step 的约定，实际为100次损失求值、99次优化器更新；首次启动路径记录错误发生在任何优化器更新之前，修复后的 flags-off20检查重复了一次，实际关闭预算为40步。以上如实记账，不把额外预检用于完整候选拟合。
