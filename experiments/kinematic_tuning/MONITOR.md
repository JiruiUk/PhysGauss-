# Live iteration monitor

Open **http://127.0.0.1:8767/** or `monitor_live.html` in this directory.
The server and local JavaScript data refresh every five seconds.

The current iteration is the latest explicit **training** iteration, checkpoint
iteration or completed metric-evaluation iteration. Rendering and evaluation
fractions such as `50/50` are shown separately as image counts. The page includes
all four variants, checkpoint/evaluation iteration counters, the active stage and
separate metric charts for the two time protocols.

```powershell
powershell -NoProfile -ExecutionPolicy Bypass -File scripts/start_kinematic_monitor.ps1
```

This monitor only reads training artifacts and writes its own `monitor_data.*`,
`monitor_live.html` and `monitor_server.json` files. The original `monitor.html`
is still generated by the frozen experiment coordinator; use the new live page
for corrected counters. Training, optimizer state, source hashes and the active
controller are unchanged.

Validation: 10 monitor/parser regression tests pass, including training-time
evaluation at 24,000 with `50/50` images, completed 50k training during a 12/50
render export, checkpoint fallback and completed-controller status. The live page
was checked in Chrome, with its iteration count advancing on the five-second
refresh; a screenshot is saved in `output/qa/kinematic_monitor/monitor_live.png`.
