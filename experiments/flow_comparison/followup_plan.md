# 两组完成后的条件式继续方案

用户于 2026-11-02 授权：先完成并比较 K1/K2；效果好则沿同一技术路径继续改进，否则尝试结构修正和同一分支。

当前两组的源码、目标、训练配置保持冻结。先完成完整训练、验证选择、最终测试导出和独立运动诊断，再决定下一组。不会在此之前根据中途结果改变当前实验。

## 判断依据

主要依据为验证选择快照上的验证图像质量与后选择验证运动诊断。测试结果作为已暴露的最终描述结果，不用来选择下一组的超参数。

实用继续门槛（单场景单种子，属于工程决策规则，并非显著性检验）：K2 相对 K1 的验证 PSNR 下降不超过 0.2 dB、验证 LPIPS 增幅不超过 5%，验证运动的 velocity-advection EPE 至少降低 10%，几何轨迹 EPE 增幅不超过 5%。四项都满足才称当前结构路径有明确的综合收益。历史 H3/J1 另作质量参照；它们不是严格的光流消融对照。

K2 的内部速度不一致为零是定义，不进入收益判定。不能以单个损失下降或去掉未覆盖像素来通过判定。没有明确收益或者只有渲染/运动一端改善，则按用户要求进入结构修正。

## 若沿当前路径继续

根据实际诊断，只选择一个有证据的瓶颈修改，例如改变光流与动量对共享表示的梯度相对强度，或修正有限差分时间尺度；不同时改多项，不加入外力/本构/未知材料参数。新增独立变体、测试和短训，再完整训练比较。

## 若尝试同一分支

候选结构：`(X,t) -> deformation Grid4D -> shared latent -> {完整 Gaussian 形变, stress_pred}`，`v = d x / d t`。形变与应力读同一时刻的共享特征，速度从完整渲染中心轨迹导出；不再依靠另一个物理网格解释同一材料点的运动。

保留原 PIDG 分支及开关关闭路径；预测应力仍为自由学习的对称六分量，不冒称满足本构关系。不增加每点自由力/刚度或材料分割。单纯共享特征不保证真实物理正确，仍需独立运动观测和动量诊断。

先测试：flags-off 输出一致；完整中心差分正确；应力损失能回传到共享 grid/latent；闲置旧头不接收梯度；快照和完整恢复包含新头；优化器确实更新新头。保留当前 K1/K2。新结构如何初始化新增参数、继承优化器和是否使用额外预拟合预算，必须先记录，不能假装和当前两组仅一个标量开关不同。

完成一项受控修改后，重复完整评估和 GT|Render 导出，据实际结果判断下一步。
