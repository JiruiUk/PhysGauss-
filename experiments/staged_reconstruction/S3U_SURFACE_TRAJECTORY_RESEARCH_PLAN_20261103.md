# 研究预案：以跨时间表面对应约束 S3-U 的三维运动与新视角成像

日期：2026-11-03

版本：v1.0，研究设计

状态：仅完成预案；本文中的实现、测试和训练均为拟开展工作，未启动新训练。

研究基线：用户选定的 S3-U，16k 图像预热后追加 6k 物理训练的最终状态。

## 1. 研究问题与目标

当前模型可以较好拟合实际拍摄轨迹上的图像，但固定相机、改变时间后，仍出现片状拉伸、碎片和孔洞。这说明观测图像拟合不足以确定正确的三维形状和运动。形变场、速度场和应力场之间的内部一致性，也不能独自证明运动符合真实场景。

本研究检验：**从真实训练图像获得的可靠表面轨迹，经过各帧相机投影约束后，能否改善同一套三维表示的跨时间运动，并进一步减少新视角伪影？**

分开回答三个问题：

1. 可见区间：可靠的二维对应能否纠正形变场，而不是仅降低参与训练的轨迹误差？
2. 遮挡区间：模型能否延续合理运动，并在重新可见时保留正确的关联候选？
3. 三维结构：二维轨迹改善是否伴随表面支持和新视角结构改善？若没有，缺失的是深度、表示能力，还是身份依据？

第一版只将问题 1 作为主要验证目标，同时诊断问题 3；问题 2 的跨遮挡身份恢复单独立项。完整三维运动恢复是长期目标，不作为第一版已经能够保证的结果。

不同相机位置的图像来自不同时刻，不是同步多视角。不能直接将不同时间的运动表面作为同一静态几何进行三角化，也不能把它们的轮廓直接相交成动态物体的 visual hull。

时间采用序列归一化时间，已有诊断按 `(原帧号 - 1) / 199` 对齐；实际训练使用元数据的 `time`。真实采集秒数尚未知，速度、加速度和时间先验必须注明归一化单位。

多个时刻可能看到了物体的多个侧面，但全表面是否得到覆盖尚未证明。相机矩阵提供投影关系，不提供被遮挡表面的形状、深度或物质点身份。

## 3. 相机、形变与观测的关系

设 canonical 点为 `X_i`，完整形变映射为 `Phi_t`，则：

\[
x_i(t)=\Phi_t(X_i),\qquad
\hat p_{i,t}=\pi\!\left(K_t[R_t x_i(t)+\mathbf t_t]\right).
\]

相机内外参固定，优化模型形变。相机运动已经包含在各帧的 `K_t, R_t, t_t` 中，二维观测不应先减去一个简单的相机平移量再当作物体运动。

S3-U 的完整中心映射来自 `UnionScene.dynamic_at()`：预测旋转作用于 canonical 坐标后，加上预测平移和统一中心偏置。新增模块必须复用这个完整映射，不能把网络中某一输出直接当作最终位移。

相机契约沿用 `metadata_cv`：

\[
W2C=\operatorname{diag}(1,-1,-1,1)\,C2W^{-1}.
\]

焦距、主点、像素中心和缩放遵循已有相机/渲染器约定；`fx = fy = W / (2 tan(fovx / 2))`。使用现有相机及可微投影接口，添加投影与实际渲染一致性测试，不混用历史 PIDG 坐标转换。

完成三维重建后，任意目标相机 `C*` 的图像可写为 `I_hat(t,C*) = Render(G(t),C*)`。这是一项预测。目标相机没有真实图像时，不存在直接的 GT RGB loss；模型自己渲染的图像也不能作为独立真值证明三维正确。

## 4. 方法设计：先建立观测，再建立固定表面支持

### 4.1 图像轨迹及其可信度

只使用 120 张训练图像构建训练对应，初始复用已有原始双向光流。先审计模型、缓存和权重来源，不使用依赖历史模型深度的 `motion/valid` 缓存作为独立观测。若后续引入多帧点跟踪器，将作为单独的数据方法变更，核验本地可用权重并记录版本，不假设已安装或已验证。

每条轨迹记录像素位置、实际时间、图像与相机来源、前后向一致性、遮挡/越界状态和置信度。检查多帧闭环与局部外观，明确光流可能同时受相机运动、形变、弱纹理和遮挡影响。正反向一致不等于真实身份成立。

第一版候选规则如下，均为**拟采用门槛，不是已有实测结果**：

- 坐标统一报告为 `px@400`，训练投影可以使用原生分辨率后按比例换算。
- 可见轨迹至少 8 个合格训练观测；前 3 个作为 bootstrap，至少另有 5 个后续观测。
- 前后向闭环误差初始上限 0.75 px@400；前景边界、混合表面、低纹理及明显遮挡处从严标记未知。
- 按序列早/中/晚三段固定采样，避免只选择早期清晰画面；抽样人工复核并记录审核范围和误差。
- 候选目标为 200 条；启动主实验的最低条件为 50 条合格轨迹，且每个时间段至少 10 条。轨迹监督组至少 30 条，轨迹损失留出组至少 20 条，留出组覆盖至少 20 个去重后的轨迹组；若分组去重后达不到条件，先补充证据，不启动长训。

不依赖连通分量个数定义物体数量，不让局部轨迹编号成为物体 ID 或材料 ID。可见轨迹中断后保留未知状态；第一版不自动跨遮挡闭合身份。

### 4.2 表面锚点采用固定局部支持，避免独立自由轨迹

第一版使用固定 Gaussian 支持集构成局部代理锚点：

\[
\hat x_k(t)=\sum_{i\in S_k}a_{ki}\,\Phi_t(X_i),
\qquad a_{ki}\geq0,\quad\sum_i a_{ki}=1.
\]

`S_k` 是绑定时固定的小范围点集，`a_ki` 是冻结的权重。这是局部表面位置的近似，不宣称 Gaussian 中心或其加权中心就是已验证材料点；也不能将其与 `Phi_t(sum_i a_ki X_i)` 混为一谈。

这样，轨迹梯度直接进入实际 Gaussian 中心及其共享形变场，没有一套可独立移动、仅用于满足轨迹 loss 的自由锚点参数。

绑定流程：

1. 从 immutable S3-U 基线出发，在 bootstrap 观测中，用真实可见贡献、局部投影和深度连续性提出支持候选；不只根据离像素最近的中心选点。
2. 支持集初始最多 8 行；用 bootstrap 观测确定非负权重并冻结。支持范围太大、混合深度层、存在多个相近候选时拒绝或记为有歧义。
3. 只用 bootstrap 数据定绑定。后续观测不以“模型已拟合得足够好”为接纳条件，以免仅选择模型本来就正确的轨迹。对后续误差和支持流失如实记录。
4. 保存检查点 SHA、点拓扑、行号、bootstrap 帧、候选差距、权重和拒绝原因。禁止逐帧改行号或重算权重以降低 loss；稠密化和行重排在第一版关闭。
5. 实际可见贡献采用经过完整性核验的前向编码渲染积分。不得将每像素最多 20 层的诊断字段当作完整贡献，也不得默认反向近似满足前向贡献守恒。

初始绑定投影残差目标为不超过 1 px@400，且需满足可见足迹和局部深度支持。深度层容差及候选差距要在训练数据 bootstrap 审计后、正式实验前写入冻结协议。若现有表示无法提供可靠局部支持，保留该失败结果，先研究表示，不用更大的点集将不同表面平均到同一像素。

### 4.3 轨迹损失及监督逃逸检查

令 `v_kt` 为来自图像观测的固定可见性，`q_kt` 为冻结置信度，则：

\[
e_{kt}=\frac{400}{W_t}\left[\pi_{C_t}(\hat x_k(t))-p_{kt}\right],
\]

\[
L_{track}=
\frac{\sum_{k,t}v_{kt}q_{kt}\,\frac12\sum_{d\in\{u,v\}}
\operatorname{Huber}_{\delta=1}(e_{kt,d})}
{400\sum_{k,t}v_{kt}q_{kt}}.
\]

误差先转为 px@400，Huber 的转折为 1 px@400，末尾除以 400 以固定数值尺度。所有合格观测在批次内统一加权归一化，避免单观测先除以自身置信度、导致正置信度相互抵消。报告指标使用未做 Huber 压缩的欧氏像素误差。

监督资格不能随当前模型的 opacity、可见贡献或重投影误差降低而自动关闭。真实遮挡由观测侧标记；对仍被观测为可见的目标，模型预测出界不能直接丢弃。已资格锚点出现非有限值或位于相机后方时，记录并暂停该分支作数值/几何失败审计，不以零 loss 继续。

本版不添加单独的支持保持 loss，而是固定以下检查集合：

- 相同支持集在可见观测中的完整 alpha 贡献、足迹位置及局部纯度；
- opacity、尺度、点间离散程度、背景外溢和被其他点替代的比例；
- 同一观测中，锚点投影误差与真实渲染支持是否一起改善。

仅将 opacity 降低不会直接降低上述位置损失，但 RGB 仍可能转由其他点解释。若出现这种脱离，H2 不通过，不能将更低轨迹误差报告为表面运动恢复。

### 4.4 后续形状与遮挡研究

局部形状约束仅在可靠表面片段内部建立，允许旋转和有界弹性形变；不要将空间 kNN 自动视为材料邻接。尤其不能在两个物体靠近或投影重叠时建立跨物体形态边。现有统一池物理邻域的跨物体风险继续记录，不宣称本版已经解决。

跨遮挡阶段保留多个身份候选或未知状态。先用受控遮挡场景验证正确恢复率、错误合并率、ID switch 与拒识覆盖率，再考虑真实序列。完全相同的物体在缺少观测的遮挡后可能无法唯一编号，合理输出可以是不确定，而不是强行给出唯一答案。

中心与协方差受同一几何映射驱动、显式持久表面等表示改动留给独立实验。如果涉及 `F`、本构或外力，遵守根 `AGENTS.md` 的 M0–M10 顺序，不在本研究中跳过前置里程碑。

## 6. 数据划分与评价设计

### 6.1 对应数据的划分

先将训练图像上的候选轨迹按重叠源 patch、重复对应和高度重合支持集分组，再以固定种子分组划分轨迹监督与轨迹损失留出集合。目标比例约为 80%/20%；样本较少时优先满足第 4.1 节的监督/留出最低数量，并公开实际比例。保存逐条分组、原因和清单 SHA；不得逐点随机拆分近重复轨迹。

留出组不得参与轨迹 loss、损失权重选择或超参数选择。其 bootstrap 信息只按同一绑定规则建立评价支持集与固定权重，不向训练器提供监督；未来观测用于评价。监督轨迹本身也单列 bootstrap 与后续观测表现。

这些留出轨迹所在图像仍可能参与原 RGB loss，因此称为**轨迹损失留出评价**，不称为完全独立的图像或三维真值。由同一跟踪器得到的留出轨迹仍有共同偏差，须提供人工审核子集；可行时另建只读验证图像轨迹作为补充，不能用它们反复调参。

原 val30/test50 图像不加入训练对应或梯度。既有历史已报告过这些划分的结果，不能宣称它们是从未查看过的新盲测集；本轮冻结方法后统一报告，未来更强泛化结论需要新的独立序列。

### 6.2 指标与证据强度

| 层次 | 指标/产物 | 可以支持的结论 |
|---|---|---|
| 观测轨迹 | 欧氏 EPE 均值/中位数/P90，PCK@1/2/5 px@400；轨迹与时间覆盖 | 可见二维对应是否改善 |
| 表面支持 | 完整贡献、局部足迹重合、opacity/尺度变化、固定支持存活、替代率 | 锚点是否仍连接实际渲染表面 |
| 图像重建 | 原生 val/test 的逐帧全幅/动态/静态 PSNR、SSIM、标准 VGG LPIPS | 已有真实观测的成像质量是否保持 |
| 新视角诊断 | 固定 2/86/188 相机 × 全 200 时间的 RGB/alpha、结构代理和原生裁剪 | 描述碎裂、薄片和拉伸变化，无 GT 时不能证明真实完整度 |
| 受控三维 | 已知点轨迹的 3D EPE、遮挡前后对应、新视角图像误差 | 方法在已知条件下是否能恢复运动与成像 |
| 原场景独立真值，若可取得 | 额外同步相机、深度、持久顶点/材料坐标 | 原场景真实三维运动、几何或身份准确性 |

LPIPS 使用 VGG、标准 `[-1,1]` 输入，报告 PNG 量化与浮点指标的区别；不混用历史非标准 LPIPS。动态与静态区域沿用固定图像定义，不以处理组渲染结果生成更有利的评价 mask。

每个模型输出相同观测帧的 GT/Render、T0/T1/基线并排图，以及固定视角并排视频。固定视角构图和亮度规则固定；代理分数不能通过模糊、填满 alpha 或合并不同物体就被解释为完整度提高。

### 6.3 预声明判定标准

以下是第一版的拟定筛选门槛，需在正式运行前与人工标注误差估计一起冻结；不是结果承诺。

1. **主要轨迹信号：**T1 在固定留出轨迹上的平均 EPE 相对 T0 至少下降 20%，且绝对下降至少达到 `max(0.25 px@400, 预先估计的标注误差分辨能力)`。按轨迹组做配对 bootstrap，95% 区间支持改善；同时报告 P90，避免只改善容易点。若对照已接近误差分辨能力，标记该集合不适合判别，不据此宣称方法无效或成功。
2. **覆盖约束：**主评价分母及轨迹集固定。模型造成的丢失、出界、失去表面支持必须计入失败/覆盖指标，不能只统计幸存轨迹。不确定的源观测资格须在比较之前冻结。
3. **表面连接：**相对 T0，T1 的“可见观测中失去固定支持”比例不得增加超过 5 个百分点，且不得出现靠大幅降低 opacity、拉散支持点而获得更低轨迹误差的系统性证据。前向贡献检测阈值与参考分母在 bootstrap 审计后冻结。
4. **图像保持：**验证动态 PSNR 下降不超过 0.2 dB，静态区域 PSNR 下降不超过 0.2 dB，标准 VGG LPIPS 相对恶化不超过 5%；均相对匹配 T0。门槛通过不单独构成几何成功。
5. **结论分级：**前四项通过，只可称“可见表面轨迹约束有效且成像代价可控”。固定视角若改善，可称“观察到结构诊断改善”。只有独立三维/新视角真值改善，才报告相应真实运动或几何恢复。
6. **复核：**首轮通过后才完成共 3 个续训采样种子的匹配复核，报告全部结果与不确定性。这是同一父模型的续训稳健性，不是 3 次独立从零训练或跨场景泛化。

## 8. 必须先通过的验证

1. **相机与时间：**CPU/可微投影/实际渲染的像素中心、坐标方向和分辨率缩放一致；同时包含相机运动和物体运动；元数据时间正确。
2. **已知运动：**受控平移、旋转和仿射形变下，固定支持锚点给出正确投影与梯度；多视角不足时保留深度歧义，不将动态观测误做静态三角化。
3. **锚点连接：**权重非负、和为 1；全阶段行号/权重不变；canonical、grid、deformation 收到梯度；不存在可单独拟合的自由锚点轨迹。
4. **置信度：**多个不同置信度的观测确实产生相应权重；检查旧逐观测归一化导致置信度抵消的问题；空集合返回明确“无资格样本”并禁止据此声称训练有效。
5. **遮挡与冲突：**可见时监督；观测遮挡时不要求表面投影到当前可见前景；重现歧义不强制续接；重叠物体不因空间近邻自动共享支持。
6. **监督逃逸：**将 opacity 人为降到近零或将尺度缩小，位置 loss 不能因此自动消失；锚点正确但真实支持消失时诊断必须报警；behind-camera 不被静默过滤。
7. **渲染贡献：**在超过 20 层贡献者的受控场景，前向点群积分与完整合成核对；不把截断记录当全部表面。
8. **训练完整性：**实际执行 100 步 smoke；独立进程验证连续 80 步与 40→80 恢复的一致性，包含 Adam、全部采样、RNG、轨迹状态和派生物理图；flags-off 对照在声明精度内一致；静态 S1 参数逐项冻结。

受控案例验证算子和失效检测，不替代 Rubber Duck 的原基准，也不能用其成功推断真实序列身份已恢复。

## 9. 失败结果如何决定下一步

| 结果 | 优先解释/检查 | 下一步 |
|---|---|---|
| 跟踪审核不通过或覆盖不足 | 图像证据不够，尤其弱纹理/相似物体/遮挡 | 改善观测、少量人工核验或寻找原合成器真值；不直接训练 |
| bootstrap 无可靠局部支持 | 当前 Gaussian 表示与所追踪表面无法可靠连接 | 先做表示审计，不能强行绑定最近点 |
| 训练轨迹降、留出不降 | 过拟合、对应偏差、局部支持不稳定 | 按时间/视角/置信度分层检查，不自动增权 |
| 锚点误差降、表面贡献消失 | 轨迹代理脱离实际成像，或模型更换解释基元 | H2 不通过；再设计支持/表示耦合的独立实验 |
| 二维与表面支持改善、新视角仍碎裂 | 深度与背面欠约束，或几何表示不足 | 优先独立深度/同步视角；可靠邻接成立后再做局部形状消融 |
| 可见跟踪改善、跨遮挡仍有歧义 | 缺少可辨别的身份线索 | 单独评估多假设重识别，保留未知 |
| 图像保持门槛失败或数值异常 | 目标冲突、梯度保护、绑定或单位错误 | 停止扩大，保留失败终态与日志，先定位再版本化修订 |

不预先把失败归因于物理不够强、缺少外力、刚度不合适或必须增加物体数。
