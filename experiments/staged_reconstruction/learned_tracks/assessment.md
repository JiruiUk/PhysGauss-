# CoTracker3：训练图像对应检查，尚未准入模型训练

来源为[CoTracker3论文](https://arxiv.org/html/2410.11831v1)及Meta官方代码，
版本和权重散列记录于`source_lock.json`。仅本地推理，无数据上传、无包安装、
无PIDG参数更新。官方模块导入会设置torch RNG，因此全部推理在独立进程。

输入为train120的RGB，不读取val/test RGB。官方预测器会强制写回查询点坐标，
因此不把forward首帧、reverse末帧的写回值当作成功预测；闭环检查使用reverse
预测返回起点。反向独立推理从forward末点发起，不把开启backward_tracking
误当独立回环验证。置信度不是材料身份真值。

三个12帧角点pilot分别获得6/12、1/3、1/6条合格轨迹；已实际查看36张缩略图，
未见明显背景漂移，但弱纹理和遮挡身份仍不确定。

扩大到28个12帧窗口，用局部5×5纹理patch提出候选（最多64，间隔4px），
保留原有0.75px闭环/方向误差、NCC≥0.6、纹理std≥2、逐帧腐蚀前景和高光
排除门槛。没有降低接受门槛。最终仅31条合格图像轨迹：早期24、中期0、晚期7。
对1064个候选，逐项通过数：前景78、可见性870、回环475、方向339、外观807、
纹理1026；这些是重叠条件，不能相加，也不据此认定唯一失败原因。

即使全部绑定成功，也不满足原R1的至少50条固定支持、每时段至少10条门槛。
因此未继续昂贵的Gaussian绑定、未分配T0/T1训练、未使用更多重复轨迹凑数。
全量轨迹图保留，但没有声称全部完成材料身份人工核验。

后续模型实验可继续；该对应分支仍为失败证据。5项质量测试及独立候选测试共
6项通过，未改变历史TV-L1分支及其冻结记录。
