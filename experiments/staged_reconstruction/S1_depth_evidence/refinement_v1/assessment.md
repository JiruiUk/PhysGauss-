# S1-D1：连续深度细化有局部收益，尚不足以确认干净完整重建

两例各96张RGB的只读深度细化与独立评估完成。18测试通过；原候选成员、
所有未更新深度逐项一致，flags-off在每个CUDA分块返回原tensor。源码/协议/
原深度及训练输入冻结，评估前所有RGB与GT文件哈希核验。没有高斯训练、
本构或物体身份推断，也未恢复未通过准入的S1-N真实续训。

静态深度MAE下降约3.15%，法线平均误差下降约13.3%，两例薄结构和误差尾部
均有有限收益。细化保留原匹配盆地，没有生成缺失面或删除点。约20.3%的候选
仍未与同射线静态GT在0.05范围内一致；尾部和法线噪声仍大，不应转为全图
强深度/法线伪GT。不能将约35%点被更新误称为35%伪影清除。

实际查看两例训练索引0/24/72（c00_t1/c08_t0/c24_t0）的深度/绝对误差和
固定邻域法线误差原图：部分离散条带与法线噪声减少，底座、边界和缺失证据
仍明显。黑像素表示无可用深度/无评估样本，不代表空几何。此处没有Gaussian
RGB、PLY或新运动视频，因此不把这些深度诊断当作新渲染模型的视觉成功。

原4源拟合和另2源验证分离，但后2源也参与过原准入；它们是算法接受证据，
不是独立评估。独立性来自只供评估的解析GT。法线比较固定原始有效像素，
避免细化改变有效集合后制造平均数改善。0.02/0.05只是既定诊断尺度，未用于
训练筛选或事后调门槛；0.05大于薄板厚0.04，厚度恢复仍没有被证明。

判定：保留D1为一个有限数值改进，不升级真实3DGS，不启动S1-N18k→24k，
不重跑或增加D1网格/阈值。下一步优先一个RGB多视角不确定性候选，利用源
视角间的几何分歧表达深度区间/置信度；先固定协议并独立审计是否能暴露错误
盆地与薄结构不确定性，再决定稳健区间深度约束的配对Gaussian合成训练。
不直接加法线损失、不把低置信度称为动态/背景，也不依据GT筛选训练像素。
若这一路径同样无法区分错误与正确表面，再向用户报告需要补采或独立几何先验
的实测平台期；当前不凭局部改进承诺最终伪影已降低。

证据：inference.json、evaluation.json、exports.json、source_freeze.json及对应日志。
