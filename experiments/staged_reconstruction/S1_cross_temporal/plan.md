# S1-CT：跨时间几何支持与可更新置信度

用户授权尝试借鉴 Cross-Temporal 3DGS 的选择性跨时间融合。这里没有论文的高质量历史3DGS，也不复现其DUSt3R；从训练RGB、相机和时间冷启动。旧S1-A的训练RGB/LK发现证据可复用，但不加载旧模型、静态颜色标签或视觉壳。

固定协议先于结果保存。新增跨较大时间间隔SIFT互检和已知相机极线检验；合并轨迹时禁止同帧冲突，交错观测拟合/检查固定世界点。新轨迹最少6观测/40时间跨度，区别于旧LK的12观测协议；不可把与旧S1-A的改善全部归因置信度。

由几何锚点在已观测图像中的种子建立初始置信度；把同一固定世界点投影到其他时刻，仅在RGB相容、多锚点且无矛盾轨迹的通用区域建立候选上限。未知区域不能仅凭低训练误差变成静态。遮挡和纹理歧义保留为局限。

两组使用完全相同候选初始化、相机序列、12k步和优化器：fixed固定初始置信度；progressive每1k步在400px图像上更新置信度，允许增减监督。几何始终给置信度上限；缺失渲染alpha不是背景负标签。两组都不接动态池，不估计物体数。

先进行合成机制测试、候选掩膜实际查看、原生渲染对照及独立进程恢复（含置信度/Adam/相机/RNG），再分别执行正式训练。训练与评估检查冻结源码和历史检查点。每个里程碑独立提交，保留失败收据。

比较共同冻结S1-A区域上的代理误差、候选覆盖/未知比例、独立验证相机推断区域、原生固定86/188及早中晚图、200原轨迹视频。验证区域同样是推断标签；没有独立几何GT，不能宣称静态召回率、真实接触表面或完整几何正确。
