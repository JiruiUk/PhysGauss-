# J8：J7＋长期观测记忆，完整匹配实验

结论：已经完成两臂各2000步的原生Gaussian联合训练。记忆降低了局部轨迹重投影误差，
验证RGB非退化门槛通过，但没有稳定改善鸭子表面的完整性与拖尾清理，不替换原J7。
这是当前固定候选的结果，不能据此断言时序模型无效或RGB数据无解。

## 模型和训练起点

- 两臂均从J7 `colorfree_static` final2k的完整状态出发，SHA256
  `56496592beb55daf82444e34268b8e7b772a5819fa686cc5b95e3c63d348e4ad`。
- 保留3273个静态Gaussian及15507个未知数量统一动态池Gaussian。
  静态库来自不使用蓝色阈值的RGB/几何重建；动态分支的历史颜色条件来源仍然存在，
  本次不能称为从零完全无标签重建。没有新颜色掩膜、物体数量或独立GT输入。
- 两臂均更新静态opacity/SH及动态canonical/grid/deformation；静态XYZ/scale/rotation、
  physics模型/Adam/图缓存及拓扑冻结。纯RGB重建续训，不称为physics续训。
- 相同J7模型、两个Adam、RNG、相机栈及2000步预算；相机轨迹逐步匹配。
  动态Adam28000→30000，静态外观Adam20000→22000，静态几何18000、physics800保持。
- 两臂都保留`0.8 L1 + 0.2 DSSIM + 0.1 static self-depth`，深度教师是各自
  完全相同的初始J7静态库。该教师只是自身参照，不是几何GT。

## 长期记忆具体是什么

这是可保存的RGB观测记忆，不是新增Transformer/RNN。复用冻结L4观测拼接算法，
保留原权重0.01及全部准入/撤销门槛，不扫参、不放宽条件。

730条已保存双向RGB追踪短轨迹全部保留。只用偶数训练索引的重叠观测选择相邻窗口
连接，奇数索引验证连接；原T4高斯编号只能提名。重新计算J7全部120时刻、每时刻15507点
的世界轨迹，重新检查投影、互换绑定、原生可见贡献和RGB patch一致性。
旧J6世界坐标、记忆准入名单和置信度没有移植。

训练时，对同一canonical高斯在当前已观测帧和最多4个远端已观测关键帧的投影误差、
投影位移误差进行稳健约束。每个投影使用自己的真实相机位姿，因此没有把屏幕位移
直接当成世界运动。几何/可见性/纹理不足时暂停，连续两次矛盾撤销，连续两次通过恢复；
缺口不插值，不创造3D深度、物体身份、新表面或不可见观测。

| 记忆分母/阶段 | 实测 |
|---|---:|
| 原始短轨迹 | 730，全部保留 |
| 拼接后的全部记忆 | 641 |
| 16–20次观测的跨窗口记忆 | 75，其中29条有合格历史编号提名 |
| J7几何重新绑定通过 | 21条，共360次观测 |
| 初始原生检查活跃 | 17条/17个高斯，共292次观测 |
| 初始前/中/后三段观测 | 276 / 16 / 0 |
| 第1750步末次复核活跃 | 8条/140次观测，均在前段 |
| 末次暂停/撤销 | 12 / 1，全部保留 |
| 2000步中实际使用记忆 | 203步，10.15% |
| 实际关键帧端点对/记忆应用 | 3634 / 1414 |
| 全步平均加权记忆损失 | 0.00007453218 |

该覆盖不足以称为全时段、全鸭子表面长期记忆。初始17个受支持高斯只占动态池约0.11%，
也不能把一个受支持高斯等同于一个物体。相关范围限制在看结果前即已披露。

## 轨迹结果及其边界

对所有21条原始J7几何绑定通过的记忆、360次观测统一评估，不按最终活跃状态删样本；
三模型无投影缺失。偶数/奇数分别180次观测：

| 模型 | 偶数fit平均误差 px↓ | 奇数held平均误差 px↓ |
|---|---:|---:|
| J7 | 0.852436 | 0.877507 |
| 普通续训 | 1.026963 | 1.026156 |
| 记忆续训 | 0.652001 | 0.650365 |

相对匹配对照，fit/held误差分别减少36.51%/36.62%。held没有加入记忆辅助损失，
但其RGB仍参与普通图像训练，因此不是独立新视角或独立3D GT。不能从较小重投影误差
推出厚度、表面连接或整只鸭子的完整性已经恢复。

## 固定视角和分解图实际复核

实际复核固定86/188的早、中、晚RGB比较、6张分解图、6张原生候选RGB、
6张训练轨迹对照和RGB/alpha/D重点图。两视角的立柱/底座RGB主体保持，
静态广alpha支撑/尖刺没有被本次实验消除。

动态部分仍有碎裂、薄片、条带和颜色很暗的高alpha占据。固定86晚期的椭圆状
高alpha团块仍然存在；固定188中期仍有横向尖长拖尾，不能判为清理成功。
训练轨迹图通常更接近观测，固定相机跨时间组合仍明显失真。

以下只是统一阈值下的渲染代理统计：全动态RGB各通道<0.05且动态alpha>0.5；
每组分母都是1440000像素。没有据此删点、赋予背景标签或选择训练点。

| 相机/时刻 | J7暗高alpha像素 | 普通续训 | 记忆续训 |
|---|---:|---:|---:|
| 86 / 2 | 1044 | 1088 | 1040 |
| 86 / 100 | 58039 | 51912 | 50902 |
| 86 / 200 | 76428 | 46159 | 57522 |
| 188 / 2 | 4219 | 4675 | 4684 |
| 188 / 100 | 29086 | 29113 | 28133 |
| 188 / 200 | 61905 | 54056 | 54625 |

结果有好有坏：86晚期记忆臂比对照多24.62%的暗高alpha像素，不支持一致清理。
这些数值不是物体GT面积，也不能把暗色点直接认定为错误背景。

静态alpha>0.5支撑：86为232832→232799，188为226412→226384；
父支撑各有39像素降到阈值以下。自身父支撑D/alpha变化约0.000316/0.000331。
这支持“静态渲染主体大致保持”的有限判断，不能证明静态几何准确；D/alpha本身是渲染代理，
黑色低alpha区域是缺失，绝不记为零几何误差。

## 实现和完整性核验

- 18测试通过：原冻结记忆单测及J7绑定/默认关闭检查。
- 独立730轨迹/8760原始观测记账、fit/held隔离及完整绑定重放通过。
- 原生RGB/alpha/D关闭开关同值、J7 RGB＋自身深度梯度一致、记忆梯度有限且进入
  canonical/grid/deform、异常路径恢复RNG/flags及不改变模型/Adam检查通过。
- 两臂各20步短训和各两个独立恢复进程通过。使用用户已批准的完整精确状态恢复、
  原生梯度原容差及同份原生梯度Adam精确更新验收，原epsilon1e-15不变。
  既往40步CUDA训练轨迹不一致记录保留，不改判。
- 532训练源/输入、35评估源/输入冻结；独立120时刻全15507点轨迹及相机重放通过。
- 4000相机采样、双Adam各组步数、physics/图缓存冻结、七次原生记忆刷新及控制状态
  逐值独立重放通过。保留完整checkpoint/Adam/RNG/相机/控制器与模型快照。
- 输出180张原始诊断/比较PNG、6份完整Gaussian PLY与9份世界XYZ诊断PLY。
  两个H264/yuv420p/faststart视频各200帧，最终独立核验见`final_validation.json`。
  没有测试浏览器播放，也没有固定跨时间视角独立几何GT。

## 结果与后续边界

本候选的局部时序绑定收益保留；整体结构清理门槛未通过，状态`completed_not_promoted`。
原J7保留，不自动替换、延长训练或扫权重。只有一次匹配CUDA训练对，不声称稳定因果效应。

当前直接证据是记忆覆盖稀疏且偏早，监督已有点的投影并没有建立完整表面或自动补出
新表面连接；这不是“长期记忆无法工作”的证明。若继续研究，首先应固定更广时间跨度的
可靠表面记忆/重现关联与覆盖验收，再检验其邻域传递，避免只放大同一小组轨迹的损失。
本轮没有自动实施该后续候选。
