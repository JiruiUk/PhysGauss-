# I5：局部刚性约束，16k预热准入失败

按预定配置，从原S3-U第0步完整状态训练16,000步，原始相机、800→1600宽度
计划不变。旋转感知邻域先验作用于310,038条有向边，覆盖99.9936%的初始点。
8项单元测试、关闭路径损失/梯度比较、20步强制physics路径短测、独立40→80→200
续训及正式16k完整状态审计均通过。没有新材料参数、力或实例/物体数量输入。

验证30帧的预热指标：全局PSNR26.992201、动态PSNR21.924082、动态alpha0.949037、
静态PSNR34.504430。冻结static-only为35.643816，因此静态区域下降1.139386dB，
超出原1dB准入护栏。原S3-U同16k预热动态PSNR为23.990448；I5低2.066366dB。
程序按规则终止，物理调用为0，未运行6k正式物理阶段，也没有读取test RGB。
预热alpha门槛原为0.85；不能因其通过就当成最终0.95门槛通过。

实际查看fixed86/t86及fixed188/t43、t146、t200的1600×900原图。
fixed188/t43仍有明显黑色缺失与零散点，t146仍有拉长形状和缺失，t200包含
模糊、不完整形状；fixed86/t86有局部碎片。完整性明确失败，未做1200帧最终验收。

`warmup_state_audit.json`只证明16k执行状态正确，不能代表实验成功；
`warmup_admission.json`保留原始失败。未修改已冻结源码、先验权重或验收阈值。

下一步不继续叠加同类局部损失。检查更强的共享运动表示，从初态直接让少量
连续控制点驱动整套Gaussians。该思路来自SC-GS及低秩粗形状方法，需独立
验证render/physics使用同一中心映射，并与原S3-U相同16k+6k预算比较。
控制点维数不作为物体数量，不使用实例或材料标签。其效果仍须实际训练验证。
