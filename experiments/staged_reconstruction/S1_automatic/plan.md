# S1-A：未知静态区域的几何发现与3DGS重建

用户要求不预知蓝色/任何区域是静态。输入为异步训练图像、时间与数据提供的相机参数。RGBA仅按原数据协议合成黑底RGB；alpha不参与静动分类或监督。不使用S1权重、视觉壳、原颜色筛选轨迹、蓝/黄掩膜、实例数或材料标签。

1. 从全图提取通用特征并进行双向光流检查；相机运动产生的像素移动不能当作物体运动。
2. 用一半观测三角化固定世界点，另一半观测检查重投影；结合时间跨度与视差给出条件静态候选、不符合固定点或未知。短时静止不等于永远静止，跟踪失败不等于动态。
3. 用几何候选支持通用图像区域，混合/无证据/遮挡保持未知；实际查看推断掩膜。由跨时刻几何支持独立初始化静态3DGS，再进行独立训练。
4. 先测试、初始化证据门槛、原生渲染对照、40→80独立进程恢复；通过后执行预定12k静态重建。无证据不使用蓝色规则兜底，不根据结果扫阈值。
5. 报告重投影、覆盖和未知比例，查看原生固定86/188/原轨迹。训练发现与独立几何GT区分；旧S1仅为带先验的历史参照，禁止把零时变误差当作几何成功。

本分支默认关闭，不修改PIDG或已冻结S1/S3-U。S3-U保留为动态表示基线；其黄色动态初始化/覆盖目标也仍含外观先验，不能只替换静态支撑就称为全场景无语义先验重建。新的静态结果通过复核前不接入物理，不恢复历史自动化，不估计物体数或引入本构/接触/未知力。

## 12k实测与修订

17项测试、原生渲染对照和40→80独立进程恢复通过。全图轨迹中97条符合固定点假设、200条不符合、515条未知，初始化543个静态高斯并完成12k训练。51/120张训练图有正支持，41张达到训练资格；正区域占所有训练像素0.6507%，分母包括背景和动态内容，不是静态召回率。选择条件下的训练区域PSNR24.069166dB不能与旧S1的验证PSNR比较。

实际图像显示晚期部分水平支撑面可拟合，但高立柱大部缺失，早期视角仍有模糊碎片、尖刺和光晕。因此拒绝作为S3-U静态替换，不宣称完整自动静动分解已成功。保持本次负结果，不放宽阈值或使用颜色规则兜底。

后续依赖是跨更大时间/视角基线的可靠对应、遮挡与弱纹理区域的几何覆盖验证；几何发现与RGB重建需要结合，不能只在被选中的容易区域优化并据此评分。独立合成几何评估继续保留。完整无语义先验的动态重建还必须移除旧S3-U黄色初始化和覆盖目标，本次没有替换或续训旧模型。
