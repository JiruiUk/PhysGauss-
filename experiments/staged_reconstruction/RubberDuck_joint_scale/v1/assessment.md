# L7-J：Rubber Duck跨帧联合尺度与更广RGB锚点

结论：联合尺度标定有局部收益，但可靠动态深度支撑仍不足，不启用弱深度训练，保留J6。
本轮完整执行了用户要求的跨帧联合标定与锚点扩展；不是新的Gaussian训练或几何清理成功。

## 实际方法与输入

841d7c0d在新追踪/标定输出前提交固定协议、实现、测试和输入冻结。
复用L7-P全部120张训练RGB的固定Depth Anything V2 Small原始输出；不换模型、不微调，
不引入颜色阈值、语义/静态掩膜、物体数、GT深度/法线、验证图像或新的物理量。
J6及其历史颜色条件来源仍披露，父模型深度没有用于尺度拟合。

在28个12帧窗口的全图8×8网格内提取Shi-Tomasi纹理点，固定参数双向金字塔LK，
复用原0.75px互反/闭合、NCC≥0.6、纹理标准差≥2及正深度、视差、1px三角化重投影检查。
LK状态不是学习可见性或独立几何GT，未替换原T4动态绑定资格。
1981个种子全部保存，963条通过RGB追踪检查，265条进一步静止相容；
与原362条合计627条。它们只是静止相容假设，不是静态标签或物体身份。

重叠至少2帧、每个重叠观测≤1px的重复轨迹合并为507组，最大组5条；整组哈希划分
fit/check及两份互斥fit子集，同一组不跨时刻泄漏到另一侧。每帧4px格去重，
同格有check时只保留check，7524个观测变为5351个不同格锚点观测。

每幅原始相对逆深度以全图中位数与q90−q10归一化，联合拟合120组正斜率/截距。
目标为按每帧样本数归一的相对逆深度Huber误差，加固定0.05二阶时间差分惩罚；
Huber尺度0.05、极小ridge和正斜率下界均固定。两份互斥fit子集独立联合拟合。
所有held点仅作检查，不能改系数；局部6fit/4check、每半至少3fit、空间跨度和
逆深度跨度、held与分半中位数≤5%/P90≤10%及当前帧fit凸包要求保持。
时间平滑是先验，不能作为尺度正确性证据，也不能扩大当前帧空间监督范围。

晚期只有3/40张通过，比同锚点逐帧5张更少，因此不能说联合标定全时段都改善。

全部120帧的潜在fit凸包平均图像面积从6.846%增至12.884%，包括未通过标定的帧。
这是二维插值范围，不是鸭子表面覆盖、独立GT面积或准确射线覆盖；凸包内部也可能含空区。
固定0/24/72/119实际看图显示：新增点仍集中立柱、底座边缘，鸭子大部分表面没有直接尺度锚点。
原始Small对黑背景仍给有限连续值，未将其解释为表面或用黑色分类。

联合检查失败分母120：68张锚点/尺度不一致，5张分半fit不足，8张锚点不足，39张通过。
主拟合有8帧的归一化斜率触及正下界，其中16/18两帧通过既定局部检查；这些近常深度解
尤其不能说明先验已恢复表面形状。原协议不作事后改判，但报告此局限，不据其升级。

## 决策

本轮支持“扩展RGB锚点与跨帧联合尺度能增加部分局部可检查证据”，不支持
“已获得足够动态深度监督”或“伪影/完整性已经改善”。状态completed_audit_not_admitted，
保留J6，弱深度继续默认关闭，不延长训练、不提高权重、不放宽门槛或自动换模型。
若继续，应针对晚期held锚点的不一致及鸭子表面的可观测尺度支撑，另立一个可检验机制；
不能只靠更强时间平滑或把父渲染深度当正确深度来补满覆盖。
