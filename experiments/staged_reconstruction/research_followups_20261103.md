# 持续完整度研究：新增文献核查

当前固定视角验收未通过。此文是后续研究记录，不表示下列方法已经接入PIDG。
I5已冻结其独立配置；不依据训练中间图像暗改该轮损失或门槛。

| 原始论文 | 可借鉴的约束 | 当前证据与限制 |
|---|---|---|
| [Dynamic3DGaussians,3DV2024](https://dynamic3dgaussians.github.io/paper.pdf) | 邻域相对向量需遵循局部旋转，附近旋转保持一致 | I5改编该思想；原论文为同步27训练相机和深度初始化，本数据每时刻单视角，不能直接继承论文结论 |
| [MoDGS,ICLR2025](https://arxiv.org/html/2406.00434v4) | 先初始化可逆形变，再融合多时刻深度点，另加鲁棒深度排序 | I3/I4仅测试排序，未实现论文的完整3D初始化。失败不能推出整篇方法无效；现有深度标定/对应证据不足以直接融合成GT |
| [DG-Mesh,ICLR2025](https://arxiv.org/html/2404.12379v3) | 将动态Gaussians与可微重建表面联合优化、双向形变及mesh anchoring | 能提出更强的表面覆盖先验；需要新的表面分支、可微网格与独立预检。仅导出/封洞网格不能算模型已恢复完整 |
| [USplat4D,ICLR2026](https://arxiv.org/html/2510.12768v2) | 用时变不确定性选可靠锚点，构建图并约束不可靠点的插值运动 | 可检查I1均匀邻接是否混入不可靠运动。论文自身承认：基础先验没有可靠运动/几何时，不能补出缺失结构；不能把可见性或低残差直接当身份真值 |
| [4DGS in the Wild,NeurIPS2024](https://arxiv.org/html/2411.08879v1) | 由训练图像渲染贡献评估不确定性，并处理动态区域初始化不足 | 可审计哪些Gaussians长期未被观测支持；仅加权平滑未观测点仍不足以确定其正确位置 |
| [Neural Parametric Gaussians,CVPR2024](https://arxiv.org/html/2312.01196v2) | 先学跨时间共享的低秩粗形状，再在局部可变形体积中安置Gaussians | 若局部刚性仍只能平滑薄片，需要检查更强的形状/运动共享；不能将隐变量维数解释为物体数量。论文也存在canonical变成平面的失败案例，不保证完整 |

当前先完成I5的独立训练与原生跨视角检查。另做不读RGB的固定邻域协方差诊断，
比较canonical与时变位置的拉伸/厚度变化。其结果只是模型内部形状代理，
不取代图像验收，也不声称有独立几何或材料点真值。

## 固定初始邻域的只读诊断

`motion_patch_geometry_before_I5.json`使用15,499个固定patch，每个patch取初始
canonical点及32邻居，初始最大半径≤.08。先后比较S3-U、I1、I3和已拒绝的I4，
不读取任何RGB、不更新模型。其协方差谱只描述这些提议邻域的形状。

I4在9个时刻有48.4%–93.5%的patch，半径（协方差trace平方根）超过其当前
canonical的2倍。这与实际看到的拉散/长条相符，不能仅用“点云变薄”概括。
I1将S3-U晚期最小厚度降至canonical四分之一以下的比例，从约16%–17%降至
约2%，但它的实际图像仍未完整。该反例直接说明：即使几何代理明显改善，
也不能放弃原生视角图像检查。I5结果未知，不能由此诊断预先准入。
