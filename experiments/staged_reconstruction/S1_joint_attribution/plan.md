# S1-J2：冻结联合模型的透明度/颜色与准确射线分解

J1-A四臂训练完成并拒绝升级（661d3158/a1267a65）：RGB外溢下降约69–70%，
但准确静态射线覆盖下降4.378/4.998百分点。本阶段只解释已发生的变化，
不训练、不更新Adam、不改原门槛，不输出GT训练资产。

固定两条件，使用J1-A的frozen_static与revisable_static最终6000检查点。
先断言静态几何/行身份相同，控制静态全部值等于原父模型。固定2×2：
父opacity+父SH、候选opacity+父SH、父opacity+候选SH、候选opacity+候选SH。
只作原生static-only渲染，不把这些反事实叫作四个新训练模型。
同opacity两种SH的alpha和累计深度须逐值相同；GT仅独立评估。

对原32相机时间0（含原8未见相机）分别报告所有静态GT表面与薄结构分母。
用原alpha>0.5、|D/alpha-GT|<=0.05判据，将每个表面像素分类为准确、
有效但不准确、缺失。完整3×3转移表闭合lost/gained/net及各分母；区分
失去准确性的低alpha/非有限缺失和仍有效深度偏移，不把4–5百分点都叫破洞。
统计共同有效像素signed/absolute深度位移和GT误差变化。

RGB报告原clean_GT_PSNR、全图MSE、原静态RGB外溢，以及固定2×2差分和
对称平均边际贡献（opacity/SH与交互）。这只分解固定参数下的渲染变化，
不是联合训练因果归属或物理身份；SH变暗不等于清除几何。

实施前提交协议与哈希；独立统计/混合无变更/默认关闭测试，原生固定c24
两独立进程四组输出逐值重放，源/原始数据与检查点哈希核验后串行完整执行。
每例固定c0/c8/c24导出2×2 RGB和转移图，实际查看；不导出逐像素GT数组、
训练掩膜或选点。基线/候选的原射线计数及外观指标须复核原J1-A报告。
评估失败保留记录，独立代码修复；不修改冻结训练或历史评估。

依据结果另立一个结构保护联合候选，不能自动加深度/法线损失、调权重或
升级Rubber Duck。继续保留统一动态池/未知身份，原PIDG、历史和并行任务。
